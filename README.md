# career-profile

Personal portfolio site for TS Kishorkrishna, Senior Data Engineer — built with plain HTML/CSS/JS in an Apple-inspired style (no build step required).

## Structure
- `index.html` — page content
- `styles.css` — design system, layout, animations
- `script.js` — scroll reveal, stat counters, mobile nav

## Run locally
```
python3 -m http.server 8000
```
Then open http://localhost:8000
